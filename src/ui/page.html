Aturan singkat

Hal yang perlu diketahui sebelum dipakai.

  • Bucket = folder di dalam ruang identitasmu. Bucket dibuat otomatis saat pertama dipakai.
  • Key = path file di dalam bucket, boleh berisi / seperti produk/sepatu.png.
  • Identitas lain tidak bisa melihat atau menyentuh file kamu — semua akses dibatasi ke folder sendiri.
  • Ganti file = PutObject ke key yang sama; ETag berubah karena node MEGA berganti.
  • Upload besar sebaiknya lewat multipart (otomatis oleh SDK untuk file besar).
